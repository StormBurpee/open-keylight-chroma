# Open Keylight Chroma 0.2.0

Open Keylight replaces both applications in the Razer Key Light Chroma. The dashboard lives on the light: after installation, you need only a browser and your local network.

## In this release

- White light, RGB colour, saved scenes and Aurora and Breathe effects.
- Adjustable colour fades, sRGB rendering, recording lock and physical-button controls.
- A local HTTP API and MQTT discovery for Home Assistant.
- A guided Windows installer that finds the light, prepares its firmware and recovery files, and checks the five lighting channels before installing the production light engine.
- Stream Deck keys and Plus dials for brightness, colour, white temperature, power, scenes and recording lock.
- Application updates with a blue-to-green breathing progress indicator and a visible failure signal when the lighting controller remains available.

The installer also fixes two problems found during the installation rehearsal: recovery entry now follows the stock updater's sequence, and Windows credential setup works when launched from Git Bash. Pairing instructions stay visible during the final setup step.

## Install

Extract the Windows x64 installer ZIP and open **start-open-keylight.cmd**. Select your light and follow the two visual checks. The launcher prepares its own Node and Python runtimes; no developer tools or firmware paths are required.

The supported stock starting point is **ESP 1.0.13.0 and NXP 1.3.0.0** on the checked LPC11U35/501 board. The installer verifies the controller before writing. Initial Wi-Fi provisioning still requires the stock setup process.

For a light already running Open Keylight, open **System**, select the standalone ESP application and choose **Verify & update**. Install the separate `.streamDeckPlugin` file for Stream Deck. See [Getting started](../getting-started.md) for pairing and setup.

## Compatibility

Colour transitions are adjustable; white changes and Off are immediate. MQTT publishes controller-supported state, which may remain at the last static colour during an effect. Home Assistant broker discovery has automated coverage; a complete live Home Assistant installation has not been recorded.

Paired clients move to a larger storage format as they change. The old `clients_v1` record is retained for trial rollback: older firmware can revive historical tokens and cannot see newer additions or revocations. Check the [client-storage downgrade limitation](../api-contract.md) before installing an older application.

The installer downloads the pinned stock recovery image directly from Razer. It contains no copy of your settings or full device flash. An interrupted or unbootable application can still require physical recovery; application trial fallback is not a guarantee of bootloader recovery.

## Validation

Two reference lights were checked on 8 October 2026:

- The extracted Windows package completed all seven installation stages from verified stock ESP 1.0.13.0 / NXP 1.3.0.0. Each of the four controller transfers was read back in full. The operator accepted the dark and five-channel checks; the installer then verified the ESP and dashboard, paired once, checked 5% white and Off, and confirmed the application. This fixture had been restored to stock and retained earlier Open Keylight settings and clients.
- A second light upgraded from Open Keylight 0.1.9-dev through the HTTP update API. The owner confirmed it in the dashboard. Readback verified the exact new image, all four dashboard assets, healthy NXP 0.1.1.0, and unchanged settings and scenes. The owner also reported correct update and pairing feedback.
- Stream Deck 0.2.0 was installed on the owner's Stream Deck Plus. Rapid 5% brightness turns and direction reversals were reported responsive; the light recorded accepted Stream Deck commands.

The release code passes both GitHub Actions workflows: portable firmware tests, compiled NXP regressions, the ESP build, and Windows/Linux interface checks. This includes 82 installer tests, 86 dashboard tests, 51 Stream Deck tests, and 139 migration test groups with 17,388 C/Python predicate comparisons.
